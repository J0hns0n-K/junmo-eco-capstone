# Dormitory CO₂ Sensing Reliability

**Research question:** Can two low-cost CO₂/temperature/humidity sensors in a dormitory study room detect ventilation events (window opening) consistently, even when sensor placement and sampling interval change?

ECE Capstone · DICS Grade 12 · Fall 2026 · Junmo Koo

## Status
- 2026-09-30: Project started. Parts ordered (2× SCD41, 2× ESP32).

## Structure
- `web/` — public web demo (replay & compare)
- `firmware/` — ESP32 sensor logger code
- `methods/` — baseline, improvement, evaluation scripts
- `data/` — raw logs and data dictionary
- `docs/` — experiment protocol, wiring, change log
- `results/` — graphs, failure cases, report
